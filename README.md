# Online Foosball

A browser-based foosball game built with React, TypeScript, and Vite. Play locally or online with a friend via peer-to-peer (PeerJS).

## Controls

| Keys | Rods |
|---|---|
| W / S (or Arrow Up / Down) | Goalkeeper + Defense |
| A / D (or Arrow Left / Right) | Midfield + Attack |

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deployment

Pushes to `main` automatically deploy to GitHub Pages via the included workflow.
